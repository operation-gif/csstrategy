# 売上方程式 診断ツール 設定手順

「売上方程式 診断マスタ」スプレッドシートに組み込み、次の流れを自動で行います。

1. 契約企業様がGoogleフォームで診断アンケートに回答する
2. 回答を0〜4点に変換し、診断マスタの「回答」シートに書き込む（「診断結果」シートに点数が出る）
3. 企業ごとの診断シート（別ファイル）をGoogleドライブのフォルダに作る
4. SlackのCSチャンネルに通知する

```
〇〇株式会社（商品名）
診断結果が出ました
総合点 26点／一番弱い項目：④競合
診断シートはこちら https://docs.google.com/spreadsheets/d/…
```

## 準備するもの

- 診断マスタの編集権限
- SlackのCSチャンネルに投稿するための Incoming Webhook URL

## 設定手順（最初に1回だけ）

### 1. SlackのWebhook URLを発行する

1. Slackで https://api.slack.com/apps を開き、「Create New App」→「From scratch」でアプリを作る（名前の例：診断通知）
2. 左メニュー「Incoming Webhooks」をオンにする
3. 「Add New Webhook to Workspace」でCSチャンネルを選ぶ
4. 表示された `https://hooks.slack.com/services/…` のURLをコピーする

ワークスペースの設定によっては、アプリの追加にSlack管理者の承認が必要です。

### 2. スクリプトを診断マスタに貼り付ける

1. 診断マスタを開き、メニュー「拡張機能」→「Apps Script」を開く
2. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の中身を貼り付けて保存する
3. （任意）診断シートの格納先を決めたフォルダにする場合は、`REPORT_FOLDER_ID` にフォルダのIDを入れる。フォルダURL `https://drive.google.com/drive/folders/XXXX` の `XXXX` の部分です。空のままなら、診断マスタと同じ場所に「売上方程式 診断シート」フォルダが自動で作られます
4. 診断マスタのタブに戻り、ページを再読み込みする。メニューに「診断ツール」が出ます

### 3. 通知先とフォームを設定する

1. 「診断ツール」→「1. Slackの通知先を設定」で、手順1のURLを貼り付ける
   - 初回は権限の確認画面が出ます。「許可」を押してください（フォームの作成、ドライブへの保存、Slackへの送信に使います）
2. 「診断ツール」→「Slack通知のテスト」で、CSチャンネルにテスト通知が届くことを確認する
3. 「診断ツール」→「2. 診断フォームを作成」を押す
   - 回答用URL（企業様に送るリンク）と編集用URLが表示されます。控えておいてください
   - 診断マスタに「フォームの回答 1」タブが増えます。回答の生データの記録なので、消さずに残してください

### 4. 診断シートを見られる人を設定する

診断シートは、格納先フォルダの共有設定を引き継ぎます。CSのメンバーが通知のリンクから開けるように、格納先フォルダをCSのメンバー（またはチーム）と共有してください。共有ドライブの中のフォルダなら、ドライブのメンバーは自動で開けます。

### 5. 動作確認

回答用URLを開いて、自分でテスト回答を1件送ります。1分ほどで次の3つが揃えば完了です。

- 「回答」シートに点数の行が増え、W列に診断シートのURLが入る
- 格納先フォルダに「診断シート_会社名_商品名_日付」ができる
- CSチャンネルに通知が届く

確認後、テスト回答の行は「回答」シートから削除してください。

## 運用中の操作

| やりたいこと | 操作 |
|---|---|
| 診断シートを作り直す（施策マッピングを更新したときなど） | 「診断ツール」→「指定した行の診断シートを作り直す」で回答シートの行番号を入れる |
| 通知先のチャンネルを変える | 新しいWebhook URLを発行し、「1. Slackの通知先を設定」でもう一度登録する |
| 設問や選択肢を変える | 設問マスタを直してから「2. 診断フォームを作成」でフォームを作り直す。フォームの選択肢を直接書き換えると点数に変換できなくなるので、必ず設問マスタ側を直してください |

## 失敗したとき

処理に失敗すると、CSチャンネルに「⚠️ 売上方程式 診断：〇〇株式会社 の診断シート作成に失敗しました」と通知されます。よくある原因は次のとおりです。

- 設問マスタの選択肢と、フォームの選択肢が一致していない → フォームを作り直す
- 「回答」シートの見出し（①-1〜④-4）が変わっている → 見出しを元に戻す
- 格納先フォルダの権限がない → `REPORT_FOLDER_ID` のフォルダを確認する

原因を直したら、「指定した行の診断シートを作り直す」で作り直せます。
